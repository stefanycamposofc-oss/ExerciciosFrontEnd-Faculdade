# Olho Vivo: Portal de Notícias

Site desenvolvido como atividade avaliativa da faculdade, com o objetivo de apresentar a estrutura de um portal de notícias moderno e interativo.

---

## 📋 Sobre o projeto

O site foi construído explorando componentes interativos do framework **Bootstrap 5**, integrando ícones do **FontAwesome** e conceitos de layout responsivo com sistema de grelhas (*Grid System*).

---

## 🚀 Funcionalidades

- Barra de navegação responsiva com menu suspenso (*Dropdown*) e campo de pesquisa
- Carrossel de imagens automático (*Carousel*) para destaques de notícias
- Cartões organizadores de conteúdo (*Cards*) com temas de cores
- Seção de notícias em destaque com sistema de acordeão (*Accordion*) interativo
- Layout totalmente responsivo para dispositivos móveis e desktop

---

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **FontAwesome**
