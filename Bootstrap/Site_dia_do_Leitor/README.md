# Entre Páginas: Portal Literário

Site desenvolvido como atividade avaliativa da faculdade, com o objetivo de apresentar um portal literário focado no incentivo à leitura e na valorização da literatura brasileira.

---

## 📋 Sobre o projeto

O site foi construído explorando componentes interativos do **Bootstrap 5**, estilização personalizada em **CSS3** através de variáveis (*Custom Properties*) para criar uma paleta temática de papel envelhecido, além da integração com **FontAwesome** e fontes do **Google Fonts**.

---

## 🚀 Funcionalidades

- Barra de navegação fixa (*sticky-top*) com tema personalizado e campo de busca
- Carrossel de imagens (*Carousel*) para destaques visuais do portal
- Seção de autores brasileiros com janelas modais (*Modal*) detalhadas
- Quiz interativo de recomendações de leitura baseado no clima/humor do leitor
- Seção de notícias e dados estatísticos sobre a leitura no Brasil
- Painel de perguntas frequentes recolpável (*Accordion*)
- Navegação fluida por ancoragem de seções (*Smooth Scroll*)

---

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **FontAwesome**
- **Google Fonts** (Playfair Display)
